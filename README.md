## 🛠️ Tech Stack

This project is crafted using lightweight, modern web standards without heavy frameworks to ensure maximum performance and SEO compliance:

* **Markup:** HTML5 (Semantic Structure, Schema.org Structured Data)
* **Styling:** CSS3 (Custom Properties, Flexbox, CSS Grid, Glassmorphism, Keyframe Animations)
* **Hosting:** GitHub Pages
* **Optimization:** Fully Responsive, Mobile-First Design, Fast Load Times

---

## ✨ Features

* **Red Neon Aesthetic:** Custom pulse-glow animations and a developer-focused dark color scheme (`#0b0f19`).
* **SEO Optimized:** Complete with meta tags, Open Graph protocols, and JSON-LD structured data for search engine visibility.
* **Interactive Sections:**
  * **Hero Section:** Dynamic intro with custom glowing avatar frame and quick-action buttons.
  * **Tech Marquee:** Continuous highlight of core programming languages and tools.
  * **About Me:** Professional background summary detailing university studies and focus areas.
  * **Skills & Projects Grid:** Categorized cards showcasing technical competencies and software systems.
  * **Contact Section:** Direct communication channels and social links.
